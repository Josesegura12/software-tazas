# Sublima Fácil

Editor de fotos sencillo para negocios de sublimación: eliges el producto, pones tu imagen y la imprimes en espejo a tamaño real.

## Cómo usarlo

Abre `index.html` con doble clic (Chrome o Edge). No necesita instalación.

1. Elige el producto (taza, termo, playera, cojín, pluma, llavero…) o crea tu propia plantilla.
2. Sube tu imagen: arrástrala, haz clic o pégala con Ctrl+V.
3. Ajústala: Rellenar, Completa, Estirar, o mueve y alarga con las agarraderas.
4. Imprime desde el **Editor de impresión** (A4 por defecto, en espejo, varias piezas por hoja y marcas de corte).

## Funciones

- Plantillas de productos a 300 DPI, con sangrado y zona del asa en tazas.
- Textos, figuras, marcos y collage de 2, 3 o 4 fotos.
- Edición de imagen: color, filtros, nitidez, recortar, borrador y quitar fondo.
- Vectorizar imágenes y descargarlas en SVG (requiere internet).
- Vista previa en el producto para mandar al cliente.
- Diseños guardados, guardado automático y deshacer/rehacer.

Al imprimir, elige **Escala 100% / Tamaño real** y el mismo tamaño de hoja.
